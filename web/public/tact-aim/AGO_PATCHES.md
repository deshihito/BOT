# AGO 側パッチ台帳（tact-aim プレイヤー）

`web/public/tact-aim/` は TACT-AIM-distilled のビルド成果物のコピー。
ここに記録した差分だけが AGO 側で上乗せされている。バンドルを差し替える
ときは、最新のビルド成果物に「現行パッチ」を再適用すること。

## 現行パッチ（AGO 側のみ）

### 2. オンライン既定（dist/src/main.js）

既定で TurboWarp クラウドサーバー `wss://clouddata.turbowarp.org` に
`project_id=831274817`（本家 TACT-AIM）で接続し、クラウドデータを共有する。

- `?cloud=off` でオフライン（初期スナップショット）。
- `?cloud=wss://...` で別サーバー、`?project=` で project_id 上書き
  （その場合の既定 project は従来どおり `TACT-AIM-distilled`）。
- 接続可否は 2026-11-22 に実測済み: Origin `https://agobot.app` の
  ハンドシェイクで本家の ☁ CLOUD1〜10 初期データが返ることを確認。

合わせて index.html のクラウド注意ボックスの文面をオンライン前提に変更済み。

### 7. Fujimi 管理者モード（dist/src/main.js + lists/stage/Buff.js + dist/src/distilled/Pen_All.js）

ユーザー名が `Fujimi`（大文字小文字は不問）の間だけ有効な管理者モード
（2026-11-22 ユーザー指示。当初の名前 deshihito から同日改名）。
原作の作者解禁（uk-400 / kz-104 が "u" キーで発動: ツリー全解放・
Money 500・Tektite 50）と同形で、main.js の 500ms ウォッチドッグが
次を維持する:

- `G.Money = 20000`、`G.Tektite = 40`
- キャラクターツリー全開放（各レコードの 6 項目目を 5 項目目で上書き）
- 護身+ を Buff_Debuff に 1 つだけ常駐（残り 999999 に補充し続け、
  重複は除去する。重複すると軽減が 100% を超えダメージが負になるため）
- 攻撃力 100 倍 / 再生 20 倍: Character_2 の現在キャラのレコードを
  直接補正する（攻撃力 = +3 項目 ×100、再生レート = +8 項目 ×20）。
  キャラ変更時はいったん元の値に戻してから掛け直し、管理者モードを
  抜けたら元の値に戻す

軽減率 99% は Buff テーブル側で作る: `lists/stage/Buff.js` の護身+
レコードの係数（7・8 項目目）を -0.4 → **-0.99** に変更済み。
これにより Buff_effect[3]（弾）/[4]（爆発）が 0.01 になり、
被ダメージが両方とも 1% になる（ただし下記の完全ノーダメージ化が
本命で、こちらは保険）。

**攻撃係数の送信クランプ（Pen_All.js の Set cloud data、2026-11-24 追加）**:
攻撃係数はクラウドのワイヤ形式で 3 文字固定幅（`Attack×100+100`、
復号は `(値-100)/100`、最大 8.99 倍）。100 倍のまま送ると "10100" の
5 文字になり、受信側は先頭 3 文字 "101" = **0.01 倍**と誤読し、
後続フィールド（スキン・チャット・速度・名前等）も 2 文字ずれて
壊れる。これが「Fujimi 状態だと攻撃が通らない」の原因だった
（PR #1136 の攻撃 100 倍が導入した不具合）。送信値を
`Math.min(999, …)` でクランプし、実効上限 8.99 倍に揃える。

**完全ノーダメージ化（Pen_All.js、2026-11-24 拡張）**: 旧仕様は
破壊レーザーと死神の鎌だけを無効化していたが、全武器へ拡張した。
Damage 手順の冒頭で「自分が Fujimi かつ正のダメージなら return」
（回復などの負値は通す）、Bullet action の Sword damage 分岐も
「自分が Fujimi なら加算自体をしない」に変更。最低 1 ダメージの床も
この経路では発動しない。

**強ホーミング＋命中時確定キル（Pen_All.js、2026-11-24 追加）**:
ダメージは被弾側クライアントが計算する仕様のため、攻撃側の強化は
「弾の所有者名が Fujimi」であることを各クライアントが判定する形で
入れてある（AGO プレイヤー同士でのみフルに効く。TurboWarp 側の
相手には送信係数の上限 8.99 倍までしか届かない）。

- ホーミング: Bullet action の Step 命令で、所有者が Fujimi の弾は
  最寄りの敵方向へ毎ステップ即時旋回する（Search first "E" +
  Direction to bullet + CS val で向きを上書き）。回収物
  （Money / Tektite / Present / エネルギーボール）と回復・
  ヒーリング・シェア系は対象外。
- 確定キル: Bullet action の Damage 命令と Sword damage 分岐で、
  所有者が Fujimi の正のダメージは 999999 に置き換える。

バンドル差し替え時は Buff.js の変更、main.js のウォッチドッグ、
Pen_All.js の上記パッチ箇所（送信クランプ / Damage 冒頭ガード /
Damage 命令 / Sword damage 分岐 / Step 命令）を再適用すること。

## 本体取り込み済み（旧 AGO パッチ）

以下は AGO 側で先行適用した後、TACT-AIM-distilled 本体に取り込まれた。
現在のバンドルは本体ビルドのまま入っているので再適用は不要。

### 旧1. ペン描画のクアッド化 → 本体 pen.ts（commit 111e659）

`PenLayer.drawLine` を丸キャップ stroke から Scratch (WebGL PenSkin) と
同じクアッド描画へ（線分＝ペンサイズ分の矩形を fill、同一点はペンサイズ
四方の正方形）。ゲーム内の文字・UI は全部ペン描画で、丸キャップだと縁の
出方が原作と違って見えたため（2026-11-22 ユーザー指摘）。

### 旧3. フェス日判定の無効化 → 本体 Title.ts（commit 084f8c7）

Title の `script6`（2026-11-24〜12-24 に日数の偶奇で Festival フラグを
切り替え MOD 側へ誘導する「MODブロック（フェスデイ）」）を無効化し、
Festival は初期値 0（通常モード）固定。2026-11-22 ユーザー指示で
本体側にも同じ変更が入った。

### 旧5. フェスアクセス表示の丸ごと削除 → 本体（commit 4e3a1b6）

Stage リスト「osamepurinフェス開催中！」（フェス会場への URL 入り）と、
Title script1 の Festival=="1" で同リストを表示する分岐を、2026-11-22
ユーザー指示で本体ごと削除（transpile.py の生成除外込み）。本バンドルは
本体ビルドの globals.js / Title.js をそのままコピーしている。

### 旧6. ペン色設定での transparency リセット → 本体 pen.ts（commit a0d5e24）

scratch-vm の setPenColorToColor は色設定時に transparency を 0 へ
リセットするが、移植側はリセットしておらず、茂み・演出などの手順が
設定した transparency（50 / 100）が後続の描画に漏れ続けていた。
実測: ロビーのグリッド線が alpha 0.5、戦闘エリアでは alpha 0 で
タイルの切れ目が消えていた（ユーザー指摘 2026-11-22）。本体で修正し、
本バンドルは本体ビルドの pen.js をそのままコピーしている。

### 旧4. スタンプ/描画への画像効果＋スタンプの回転中心 → 本体 runtime.ts（commit 111e659）

ユーザーのスクショ比較（正規版 TurboWarp との対比）で判明した描画差分:

- フォントコスチュームは真っ赤 (#ff0000) で、ゲームは color（色相回転）と
  brightness（加算シフト）で文字色を作るが、スタンプが効果未適用・描画も
  CSS filter の乗算近似だったため全文字が赤かった。Scratch のシェーダ計算
  をピクセル単位で再現（scratchTintedImage、結果はキャッシュ）。
- スタンプがコスチュームの回転中心を無視していた。中心が画像外にある
  コスチューム（Tutorial 枠: rotationCenterY ≈ -122）が大きくずれ、
  チュートリアル表示が画面中央に出ていた（原作は右下）。マップのタイル系
  スタンプの区切りずれも同因。draw() と同じオフセット計算を stamp() に適用。
