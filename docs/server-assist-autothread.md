# 自動スレッド（サーバーアシスト）

`/support` のサーバーアシスト設定から使う、指定チャンネルのメッセージを自動でスレッド化する機能です。新しいスラッシュコマンドは増やしません。

## 設定

- **対象チャンネル**: 自動スレッドを作るテキストチャンネル
- **自動アーカイブ**: 1時間 / 1日 / 3日 / 1週間
- **状態**: 機能全体のオン・オフ

設定には「サーバーの管理」権限が必要です。

## 動き

- 対象チャンネルにメッセージが投稿されると、そのメッセージから公開スレッドを作ります
- スレッド名はメッセージの1行目（最大100文字）。空なら「新しいスレッド」
- Botのメッセージは対象外
- ほかのチャンネルや、すでにスレッド内のメッセージは対象外

スレッド作成に失敗してもメッセージ処理は止めず、Botのログに記録します。
スレッド作成はバックグラウンドで行うため、レート制限待ちでほかのサーバーアシスト処理を遅らせません。同じメッセージを二重に処理しないよう、直近1000件のメッセージIDを記憶します。

## 権限

- Botに「公開スレッドを作成」権限が必要です
- 対象チャンネルで「メッセージを送信」できる必要があります

## テスト

`tests/test_server_assist_autothread.py` で、作成、名前のフォールバック、Botメッセージ・別チャンネル・オフ時の除外、失敗時のログ、設定画面の更新を確認します。
