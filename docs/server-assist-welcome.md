# サーバーアシスト: 参加・退出メッセージ

/support の「サーバーアシスト」ジャンルから設定します。新しいスラッシュコマンドは増やしていません。

## 設定できること

- 参加メッセージのオン・オフ
- 退出メッセージのオン・オフ
- 参加メッセージの送信先チャンネル
- 退出メッセージの送信先チャンネル（未設定なら参加メッセージと同じ）
- 参加・退出それぞれの文面
- テスト送信

## 使える置き換え

| 置き換え | 内容 |
| --- | --- |
| {user} | メンション |
| {name} | 表示名 |
| {server} | サーバー名 |
| {count} | 現在のメンバー数 |
| {id} | ユーザーID |

文面は Embed の description として送信します。@everyone / @here とロールメンションは無効化し、ユーザーメンションだけ有効にしています。

## 保存先

core/guild_settings.py の assist_welcome セクションに、サーバーごとの設定を保存します。既存の bot_kv テーブルとローカル控えをそのまま使います。
