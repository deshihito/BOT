# サーバーアシスト: サーバーログ

/support の「サーバーアシスト」→「サーバーログ」から設定します。新しいスラッシュコマンドは増やしていません。

## 記録できるイベント

- メンバー参加
- メンバー退出
- メッセージ削除（本文・添付数・投稿者・チャンネル）
- ロール作成・削除
- チャンネル作成・削除

## 設定

- ログの送信先チャンネル
- サーバーログ全体のオン・オフ
- 参加 / 退出 / 削除 / ロール / チャンネルを個別にオン・オフ

## 既存ログとの関係

既存の「メッセージ編集履歴」「VC入退室履歴」「モデレート履歴（TO/KICK/BAN）」はそのまま残します。この機能は、それらでは記録していない参加・退出・削除・ロール/チャンネル変更を補います。

## 保存先

core/guild_settings.py の assist_serverlog セクションに、サーバーごとの設定を保存します。
