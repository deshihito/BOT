# サーバーアシスト: Starboard

/support の「サーバーアシスト」→「Starboard」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- メッセージに設定した絵文字（既定は ⭐）が付くと、Starboard チャンネルへ転載します。
- しきい値（1〜10個）に達したときだけ転載します。
- 2個目以降のリアクションでは、転載したメッセージのリアクション数を更新します。
- しきい値を下回ると、転載したメッセージを削除します。
- 元メッセージが削除されたときも、転載を削除します。
- BOT のメッセージは対象外です。
- 自分のメッセージへのリアクションは、既定では集計から除外します。

## 注意

Starboard チャンネルは、元メッセージのチャンネルと別にしてください。同じチャンネルを指定した場合は転載しません。転載先には Bot の「メッセージを送信」「埋め込みリンク」「メッセージ履歴を読む」権限が必要です。

## 保存先

- 設定: core/guild_settings.py の assist_starboard セクション
- 転載メッセージの対応表: bot_kv の server_assist_starboard 名前空間
