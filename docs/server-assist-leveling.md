# サーバーアシスト: レベル報酬

/support の「サーバーアシスト」→「レベル報酬」から設定します。新しいスラッシュコマンドは増やしていません。

## 既存EXP・通知との関係

AGO BOT には以前からチャットEXP・VC EXP・general レベルと、レベルアップ通知（画像カード付き）があります。この機能はそれらを変更せず、レベルが上がったタイミングでロール報酬だけを追加します。EXPの二重計上や、通知の二重送信はしません。

レベルアップ通知の送信先・オンオフは、/support の「レベルアップ通知（EXP）」で設定します。

## 設定できること

- レベル報酬のオン・オフ
- レベル報酬（例: 10=ロールID。1行1個、最大10件）
- 到達したレベル以下で一番高い報酬を1つ付与

## 注意

- レベル報酬のロールは、Botの最上位ロールより下にある必要があります。
- すでに持っているロールは再付与しません。
- 既存のEXPデータは data/exp.json（EXP_DATA_PATH で変更可）に保存されています。この機能はそのデータを変更しません。

## 保存先

core/guild_settings.py の assist_leveling セクションに、オン・オフとロール報酬を保存します。

## フック

cogs/general.py の既存レベルアップ検知（チャットEXP、VC退出時EXP、VC定期tick）から ServerAssistCog.handle_level_rewards を呼びます。既存の通知処理とは別に、ロール付与だけを担当します。
