# イベント / RSVP（サーバーアシスト）

`/support` のサーバーアシスト設定から、イベントを作成して参加を受け付ける機能です。新しいスラッシュコマンドは増やしません。

## 設定

- **投稿先チャンネル**: イベントパネルとイベントを投稿するチャンネル
- **状態**: 機能全体のオン・オフ
- **パネルを送信**: イベント作成ボタン付きのパネルを投稿

設定には「サーバーの管理」権限が必要です。

## イベントの作成

パネルの「イベントを作成」から、タイトル・説明・日時・場所（任意）を入力します。投稿先チャンネルに Embed が送られ、参加・不参加・未定のボタンが付きます。

## 回答

- 参加 / 不参加 / 未定 のいずれかを押す
- 同じ回答をもう一度押すと回答を取り消す
- 別の回答を押すと、前の回答から移動する
- 回答は1人1つ。表示はその場で更新される
- 表示更新に失敗した場合は「表示を更新」で回答を変えず再表示できる

## 終了

「終了」を押すと回答を締め切ります。操作できるのは作成者か「サーバーの管理」権限を持つ人だけです。終了表示の更新に失敗した場合は、もう一度押すと表示だけを修復します。

## 制限

- イベント作成は1人60秒に1回
- 回答変更は2秒に1回
- 表示更新は2秒に1回
- 終了・表示更新の操作はメッセージ単位のロックで直列化

## 保存

`server_assist_events` にメッセージID単位で保存します。書き込みは `wait=False` と未送信ジャーナルを使い、再起動後も保持します。

## テスト

`tests/test_server_assist_events.py` で、作成、回答の切り替え、同時回答、終了権限と表示修復、表示更新、設定画面、永続ビュー登録を確認します。
