# サーバーアシスト: 提案箱

/support の「サーバーアシスト」→「提案箱」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- 提案先チャンネルに、提案ボタン付きのパネルを送信します。
- 「提案する」からタイトルと内容を入力すると、提案Embedを投稿します。
- 提案には「賛成」「反対」ボタンで投票できます。同じ人がもう一度押すと票を取り消します。
- 提案者・本文・賛成数・反対数・状態をEmbedに表示します。

## 設定

- 提案箱のオン・オフ
- 提案先チャンネル
- 「パネルを送信」で提案パネルを投稿

## 注意

- 提案パネルと投票ボタンは persistent view として登録しているため、再起動後も動作します。
- 投票数は最大500件まで保持します。
- 荒らし対策として、提案先チャンネルの権限やモデレーション設定を併用してください。

## 保存先

- 設定: core/guild_settings.py の assist_suggestions セクション
- 提案データ: bot_kv の server_assist_suggestions 名前空間
