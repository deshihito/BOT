# サーバーアシスト: 自動ロール

/support の「サーバーアシスト」→「自動ロール」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- メンバーが参加したとき、選択したロールをまとめて付与します。
- 付与できるのは、Bot の最上位ロールより下にあるロールだけです。
- @everyone と BOT 管理用の連携ロール（managed）は候補から除外します。
- 既定では BOT アカウントには付与しません。必要なら「BOTにも付与」をオンにします。
- 「自分に適用して確認」で、実際に付与できるか確認できます。

## 注意

自動ロールは権限を配る機能です。管理者ロールやモデレーション権限を持つロールを付けると、参加しただけで強い権限を得ます。付与するロールは最小限にしてください。

## 保存先

core/guild_settings.py の assist_autorole セクションに、サーバーごとの role_ids とオン・オフを保存します。
