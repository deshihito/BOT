# サーバーアシスト: サーバースタッツ

/support の「サーバーアシスト」→「サーバースタッツ」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

既存のボイスチャンネルを、サーバー統計の表示用に使います。Botが10分おきに名前を更新します。

- メンバー数: メンバー: N
- オンライン数: オンライン: N（BOTを除く）
- ブースト数: ブースト: N

「今すぐ更新」で手動更新もできます。

## 設定

- メンバー数 / オンライン数 / ブースト数、それぞれの表示先VC（設定しないことも可能）
- サーバースタッツ全体のオン・オフ

## 注意

- 既存のVCを選ぶ方式です。Botが新しいVCを勝手に作りません。
- チャンネル名の変更には「チャンネルの管理」権限が必要です。
- Discordのチャンネル名変更レート制限に合わせ、定期更新は10分間隔です。
- 表示先VCは、他の用途と分けて作成するのがおすすめです。

## 保存先

core/guild_settings.py の assist_stats セクションに、サーバーごとの設定を保存します。
