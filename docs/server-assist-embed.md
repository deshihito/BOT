# 埋め込みビルダー（サーバーアシスト）

`/support` のサーバーアシスト設定から、管理者が Embed を作って投稿できる機能です。新しいスラッシュコマンドは増やしません。

## 設定

- **投稿先チャンネル**: Embed を送るチャンネル
- **状態**: 機能全体のオン・オフ
- **埋め込みを作成**: 入力画面（モーダル）を開く

設定には「サーバーの管理」権限が必要です。

## 入力できる内容

- タイトル（必須、最大256文字）
- 本文（必須、最大4000文字）
- 色（任意、`#RRGGBB` または `RRGGBB`。空欄は白）
- フッター（任意、最大2048文字）

送信すると設定したチャンネルへ Embed が投稿され、実行者には送信先のチャンネルが ephemeral で表示されます。

## 権限

- 設定と作成は「サーバーの管理」
- Bot に「メッセージを送信」「埋め込みリンク」権限が必要です

## 注意

- 入力した内容は保存せず、その場で1回だけ投稿します
- タイトル・本文・フッターの合計が6000文字を超える場合は、送信せずにエラーを返します
- 投稿は1人3秒に1回まで（作成画面を開く制限とは別に、送信時にも確認）
- URL や画像の添付には対応していません

## テスト

`tests/test_server_assist_embed.py` で、色の解析、Embed の投稿、不正な色の拒否、設定画面と作成ボタンの権限・状態を確認します。
