# サーバーアシスト: 招待トラッカー

/support の「サーバーアシスト」→「招待トラッカー」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- Bot起動後にサーバーの招待一覧を取得します。
- メンバーが参加したとき、招待ごとの使用回数の差分から「どの招待リンクで入ったか」を特定します。
- 招待者・招待コード・使用回数をログチャンネルへ送ります。
- 招待の作成・削除イベントでもキャッシュを更新します。

## 設定

- ログの送信先チャンネル
- 招待トラッカー全体のオン・オフ

## 注意

- Botに「サーバーの管理」権限が必要です。権限がない場合、招待の特定はできず「不明」になります。
- Bot停止中に作成・使用された招待は、起動後の一覧との差分でしか判定できません。完全な追跡が必要な場合は、起動時から稼働させてください。
- vanity URL など、通常の招待以外は対象外です。

## 保存先

core/guild_settings.py の assist_invites セクションに、サーバーごとの設定を保存します。招待使用回数のキャッシュはメモリ上に保持します。
