# サーバーアシスト: 一時VC

/support の「サーバーアシスト」→「一時VC」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- 設定した「作成用VC」に参加すると、専用のボイスチャンネルを作成して移動します。
- 作成されたVCには操作パネルが投稿されます。
  - 名前変更
  - 人数制限（0〜99）
  - ロック / 解除
  - 削除
- 操作できるのは、VCの作成者と「チャンネルの管理」権限を持つ人です。
- 誰もいなくなった一時VCは自動で削除します。
- 同じ人がもう一度「作成用VC」に入った場合は、既存の一時VCへ移動します。

## 設定

- 作成用VC（ボイスチャンネル）
- 名前テンプレート（{user} / {name} / {id}）
- 既定の人数上限（0で無制限）

## 注意

- Bot には「チャンネルの管理」権限が必要です。
- 作成されたVCは、カテゴリ内の権限を引き継ぎます。
- 操作パネルは再起動後もボタンが動くように、persistent view として登録しています。

## 保存先

- 設定: core/guild_settings.py の assist_tempvoice セクション
- 作成したVCの対応表: bot_kv の server_assist_tempvoice 名前空間
