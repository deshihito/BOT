# サーバーアシスト: 応募フォーム

/support の「サーバーアシスト」→「応募フォーム」から設定します。スラッシュコマンドは増やしていません。

## 動き

- 応募パネルに「応募する」ボタンを設置します。
- 応募モーダルで、名前・応募理由・経験を入力します。
- 応募内容はレビュー先チャンネルへ送られます。
- レビュー担当は「承認 / 保留 / 不承認」を選べます。
- 判定結果は応募者へDMで通知します（DMが閉じている場合はログのみ）。
- 適用済みの応募は再判定できません。

## 設定

- 応募パネルの送信先チャンネル
- 応募をレビューするチャンネル
- 応募フォーム全体のオン・オフ
- 「パネルを送信」で応募パネルを投稿

## 権限

- 設定には「サーバーの管理」権限が必要です。
- 応募の判定にも「サーバーの管理」権限が必要です。
- パネル・レビュー先にはBotの「メッセージを送信」「埋め込みリンク」権限が必要です。

## 保存先

- 設定: core/guild_settings.py の assist_applications セクション
- 応募内容: bot_kv の server_assist_applications 名前空間
