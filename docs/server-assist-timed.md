# サーバーアシスト: タイマー告知

/support の「サーバーアシスト」→「タイマー告知」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- 毎日決まった時刻に、設定したメッセージをEmbedで投稿します。
- 最大10件まで登録できます。
- 20秒おきに時刻を確認し、その日の未送信分だけ送ります。
- 同じ日の同じ告知は二重送信しません。

## 設定

- 送信先チャンネル
- タイマー告知全体のオン・オフ
- 告知の追加・編集・削除（時刻 HH:MM と本文）

## 注意

- 時刻はBotのローカル時刻（この環境ではAsia/Tokyo）です。
- Botが停止している間の告知は送られません。
- メンションの一斉通知は行いません（Embedのみ）。
- 送信先チャンネルにはBotの「メッセージを送信」「埋め込みリンク」権限が必要です。

## 保存先

core/guild_settings.py の assist_timed セクションに、サーバーごとの告知一覧を保存します。
