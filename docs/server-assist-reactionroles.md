# サーバーアシスト: リアクションロール

/support の「サーバーアシスト」→「リアクションロール」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- 対象メッセージに絵文字リアクションすると、対応するロールを付与します。
- リアクションを外すと、対応するロールを外します。
- 対象チャンネル・メッセージID・絵文字とロールIDのマッピングを設定します。
- 「リアクションを反映」で、対象メッセージへ未追加のリアクションを付けます。

## 設定

- 対象メッセージのチャンネル
- メッセージID
- 絵文字=ロールID（1行1個、最大25件）
- リアクションロール全体のオン・オフ

## 注意

- Botに「ロールの管理」「リアクションの追加」「メッセージ履歴を読む」権限が必要です。
- Botの最上位ロール以上のロール、managedロールは付与しません。
- 既存のロールパネル（セレクト式）はそのまま残します。この機能はリアクション式の別機能です。
- 対象メッセージはBotが投稿したものでなくても構いません。

## 保存先

core/guild_settings.py の assist_reactionroles セクションに、チャンネル・メッセージID・マッピングを保存します。
