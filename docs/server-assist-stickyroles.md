# サーバーアシスト: ロール復元

/support の「サーバーアシスト」→「ロール復元」から設定します。新しいスラッシュコマンドは増やしていません。

## 動き

- メンバーが退出したとき、付与されていたロールを保存します。
- 同じメンバーが再参加したとき、保存したロールを戻します。
- Botの最上位ロール以上、managedロール、@everyoneは復元しません。
- 復元後は保存データを削除します。

## 設定

- ロール復元のオン・オフ
- BOTを除外するか

## 注意

- Botに「ロールの管理」権限が必要です。
- 退出から再参加までの間にロールが削除された場合、そのロールは復元されません。
- セキュリティ上、復元するロールはBotが管理できる範囲に限定されます。

## 保存先

- 設定: core/guild_settings.py の assist_stickyroles セクション
- 退出時のロール: bot_kv の server_assist_stickyroles 名前空間
