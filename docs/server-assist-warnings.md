# 警告（サーバーアシスト）

`/support` のサーバーアシスト設定から使う、ProBot 相当の警告機能です。新しいスラッシュコマンドは増やしません。

## 設定

- **パネル**: 警告パネルを置くチャンネル
- **ログ**: 警告を記録した Embed を送るチャンネル（任意）
- **モデレーターロール**: 警告を出せるロール（任意）。「サーバーの管理」権限を持つ人は常に操作できます
- **状態**: 機能全体のオン・オフ
- **パネルを送信**: パネルを投稿

設定には「サーバーの管理」権限が必要です。

## 警告の出し方

1. パネルのメニューからメンバーを選ぶ
2. 理由を入力する
3. 記録・ログ・DM が行われる

警告パネルは公開チャンネルに置けますが、操作できるのは「サーバーの管理」権限か、設定したモデレーターロールを持つ人だけです。理由の入力画面を開いたあとにも権限を再確認します。

## 制限

- 自動タイムアウト・キック・BAN は行いません（記録・ログ・DM のみ）
- 1ユーザーにつき直近100件の警告を保持し、通算件数は別に数えます
- DM が閉じている場合はログに残り、記録自体は成功します

## 保存

`server_assist_warnings` に `guild_id:user_id` 単位で保存します。書き込みは `wait=False` と未送信ジャーナルを使い、再起動後も保持します。同じユーザーへの同時警告はキー単位のロックで直列化します。

## テスト

`tests/test_server_assist_warnings.py` で、権限、パネルからのモーダル、記録・ログ・DM、DM失敗時、同時警告、設定画面、永続ビュー登録を確認します。
