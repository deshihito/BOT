# サーバーアシスト: カスタム返信

/support の「サーバーアシスト」→「カスタム返信」から設定します。スラッシュコマンドは増やしていません。

## 動き

- 設定した言葉と完全一致したメッセージに、Botが返信します。
- 大文字小文字・前後の空白は無視します。
- スラッシュや ! で始まるコマンドは反応しません。
- BOTの発言には反応しません。
- 同じ人・同じ返信への連続返信は3秒間抑止します。
- 最大25件まで登録できます。

## 設定

- カスタム返信全体のオン・オフ
- 言葉と返信内容の追加・編集・削除

## 注意

- 返信内容にメンションを書いても、一斉通知は行いません。
- 荒らし対策として、必要ならAutoModと併用してください。

## 保存先

core/guild_settings.py の assist_customreplies セクションに、サーバーごとの返信一覧を保存します。
