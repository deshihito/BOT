# 自動リアクション（サーバーアシスト）

`/support` のサーバーアシスト設定から、指定チャンネルのメッセージへ自動でリアクションを付ける機能です。新しいスラッシュコマンドは増やしません。

## 設定

- **対象チャンネル**: 自動リアクションを付けるチャンネル
- **リアクション**: 最大10個。カンマまたは改行で区切る（カスタム絵文字は `<:name:id>` 形式）
- **状態**: 機能全体のオン・オフ

設定には「サーバーの管理」権限が必要です。

## 動き

- 対象チャンネルのユーザー投稿に、設定したリアクションを順に付けます
- Botの投稿は対象外
- 同じメッセージは1回だけ処理（直近1000件のIDをLRUで保持）
- 付与はバックグラウンドで行い、レート制限待ちで他のサーバーアシスト処理を止めません
- 1つのリアクションが失敗しても、残りのリアクションは続けます

## 権限

- Botに「リアクションを追加」権限が必要です
- 外部サーバーの絵文字を使う場合は「外部の絵文字を使用」も必要です

## テスト

`tests/test_server_assist_autoreact.py` で、設定の解析、リアクション付与、Bot・別チャンネル・オフ時の除外、失敗時のログ、重複防止、設定画面とモーダルを確認します。
