# 投票（サーバーアシスト）

`/support` のサーバーアシスト設定から使う、ProBot 互換の投票機能です。新しいスラッシュコマンドは増やしません。

## 設定

「投票」を選ぶと、次の設定ができます。

- **投稿先**: 投票パネルと投票メッセージを置くチャンネル
- **複数選択**: オンにすると、1人が複数の選択肢へ投票できる
- **状態**: 投票機能全体のオン・オフ
- **パネルを送信**: 投稿先へ「投票を作成」ボタン付きのパネルを送る

設定の変更とパネル送信には「サーバーの管理」権限が必要です。

## 投票の作成

1. パネルの「投票を作成」を押す
2. 質問と選択肢を入力する（選択肢は1行に1つ、2〜10個）
3. 投稿先チャンネルに投票メッセージが送られる

作成した投票は、その場で集計されます。選択肢は重複を除いて保存されます。

## 投票

- セレクトメニューから選択肢を選ぶ
- 1つ選択のときは、同じ選択肢をもう一度選ぶと票を取り消せる
- 複数選択のときは、選んだ組み合わせがそのまま投票内容になる
- 投票できるのは1人1回まで。選択を変えると前の票は外れる
- 1つの選択肢につき最大 2000 人まで

結果は投票メッセージの Embed に「票数 + バー」で表示されます。

## 締め切り

「締め切る」を押すと投票を終了します。押せるのは次のどちらかです。

- 投票を作成した人
- 「サーバーの管理」権限を持つ人

締め切ったあとは投票できません。メッセージには最終結果と「締め切り」が残ります。

## 保存と再起動

投票は `server_assist_polls` に保存されます。投票操作はローカルへすぐ書き、Supabase へは未送信ジャーナル経由で送るため、応答が Supabase 待ちになりません。再起動後も永続ビューで投票と締め切りを続けられます。

## テスト

`tests/test_server_assist_polls.py` で、作成、1つ選択の切り替え、複数選択、同時投票、締め切り権限、設定画面、永続ビュー登録を確認します。
