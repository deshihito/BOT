# サーバーアシスト: AutoMod

/support の「サーバーアシスト」→「AutoMod」から設定します。新しいスラッシュコマンドは増やしていません。

## フィルター

- 招待リンク（discord.gg / discord.com/invite）
- 外部リンク（http/https / www.）
- メンションスパム（3 / 5 / 10件以上、または無制限）
- 大文字スパム（50% / 70% / 90%以上、またはチェックなし）

## 動作

- 違反メッセージを削除します。
- 設定したログチャンネルへ、理由・投稿者・チャンネル・本文を送ります。
- 必要なら 1 / 5 / 10 / 60分のタイムアウトも適用します。
- 管理者と「メッセージの管理」権限を持つ人は対象外です。
- BOTのメッセージは対象外です。
- 既定ではオフで、各フィルターもオフです。有効化したものだけ動きます。

## 注意

- AutoMod は既存の NG ワードゲーム、ハニーポット、Muted、グローバルチャットのモデレーションを置き換えません。併用できます。
- 外部リンクを許可したい場合は「外部リンク」をオフにしてください。招待リンクだけを止めることもできます。
- Bot に「メッセージの管理」権限が必要です。タイムアウトを使う場合は「メンバーをタイムアウト」権限も必要です。

## 保存先

core/guild_settings.py の assist_automod セクションに、サーバーごとの設定を保存します。
